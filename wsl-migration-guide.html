0.1 – Aprire il terminale WSL e verificare la distribuzione
WSL bash # Da Windows: Start → digita "wsl" oppure apri Windows Terminal e seleziona Ubuntu # Verifica distro e versione cat /etc/os-release | grep -E "^NAME|^VERSION" # Verifica WSL2 (deve essere WSL version 2) # Da PowerShell Windows: wsl --list --verbose
SYS
0.2 – Installare Docker Engine nel WSL (se non presente)
⚠️ Se usi Docker Desktop for Windows con integrazione WSL, Docker è già disponibile nel WSL. Verifica con docker --version.
WSL bash # Verifica se Docker è già installato docker --version docker compose version # Se NON è installato, installare Docker Engine in WSL: sudo apt-get update sudo apt-get install -y ca-certificates curl gnupg lsb-release curl -fsSL https://download.docker.com/linux/ubuntu/gpg | \ sudo gpg --dearmor -o /usr/share/keyrings/docker-archive-keyring.gpg echo "deb [arch=$(dpkg --print-architecture) \ signed-by=/usr/share/keyrings/docker-archive-keyring.gpg] \ https://download.docker.com/linux/ubuntu \ $(lsb_release -cs) stable" | \ sudo tee /etc/apt/sources.list.d/docker.list > /dev/null sudo apt-get update sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin # Aggiunge il tuo utente al gruppo docker (niente sudo) sudo usermod -aG docker $USER newgrp docker # Avvia il daemon Docker sudo service docker start # Verifica docker run hello-world
✅ Se Docker Desktop for Windows ha l'opzione "Use WSL 2 based engine" abilitata nelle Settings, docker funziona già dentro WSL senza installazione aggiuntiva.

Copia del Progetto da Windows a WSL
Portare i file sorgenti nel filesystem WSL
SYS
1.1 – Copiare il progetto nel home di WSL
Dal filesystem Windows, il progetto è in C:\Progetti\URBreath\Superset. In WSL questo path è accessibile come /mnt/c/Progetti/URBreath/Superset.
WSL bash # Crea la cartella di lavoro nel home WSL mkdir -p ~/urbreath/superset # Copia tutto il progetto (ESCLUSI i volumi Docker e i node_modules) rsync -av \ --exclude='node_modules' \ --exclude='.git' \ --exclude='target' \ /mnt/c/Progetti/URBreath/Superset/ \ ~/urbreath/superset/ # Entra nella cartella di lavoro cd ~/urbreath/superset ls -la # Crea cartella backups mkdir -p backups/pre-migration/dashboards
ℹ️ Perché copiare nel filesystem WSL e non lavorare da /mnt/c/? Le performance di Docker con volumi su /mnt/c/ (filesystem Windows) sono molto peggiori rispetto al filesystem nativo ext4 di WSL. Lavorare in ~/ è molto più veloce.

; } export default SupersetEmbed; EOF

5.2 – Aggiungere la Database Connection in Superset 6.1.0
Il nuovo Superset ha il DB metadati fresco: non conosce urbreath_dev. Va aggiunta manualmente prima dell'import delle dashboard.

  5. Selezionare PostgreSQL

# Stringa di connessione al container external-postgres-v6 # (raggiungibile tramite nome container perché sono sulla stessa rete) postgresql+psycopg2://external_user:external_pass@external-postgres-v6:5432/urbreath_dev
